# -Functions-Modules-in-Python

This repository contains two Python scripts:

1. A script to calculate the factorial of a number using recursion.
2. A script that uses Python’s `math` module to perform various mathematical operations.

---

### 🔁 Script: Factorial Calculator

**File:** `factorial.py`

### ✅ Description:
- Defines a function named `factorial` that takes a number as input and calculates its factorial using recursion.
- Accepts an integer input from the user.
- Returns and prints the factorial result.

### 📌 Sample Output: Enter a number: 5
The factorial of 5 is 120.


---

## 📐 Script: Math Module Operations

**File:** `math_operations.py`

### ✅ Description:
- Prompts the user to enter a number.
- Uses Python's `math` module to calculate:
  - ✅ Square root (if the number is ≥ 0)
  - ✅ Natural logarithm (base e, if number > 0)
  - ✅ Sine (interpreting the input as radians)
- Displays all results.

### 📌 Sample Output: Enter a number: 4
Square root: 2.0
Natural logarithm (ln): 1.3862943611198906
Sine (in radians): -0.7568024953079282
